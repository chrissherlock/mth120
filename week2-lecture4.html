1. Formal $\epsilon\text{-}N$ Convergence

📖 Notation Reference: Sequences & Limits

Don't be intimidated by the symbols! Universal quantifiers ($\forall$), existential quantifiers ($\exists$), and floor/ceiling brackets ($\lceil \dots \rceil$) are simply mathematicians' shorthand for exact logical instructions.
$\forall$Universal quantifier: "for all" or "for every"
$\exists$Existential quantifier: "there exists"
$(a_n)$Sequence: an ordered list $(a_1, a_2, a_3, \dots)$
$\lim_{n\to\infty} a_n = L$The sequence $a_n$ converges to limit $L$
$\epsilon > 0$Arbitrary positive distance tolerance
$N \in \mathbb{N}$Cutoff index past which $|a_n - L| < \epsilon$

Saying a sequence converges to $L$ means that if you look far enough down the list, every subsequent term gets arbitrarily close to $L$ and stays there forever.

Formal Definition of Convergence: A sequence $(a_n)_{n=0}^\infty$ converges to a real limit $L \in \mathbb{R}$, written $\lim_{n\to\infty} a_n = L$ or $a_n \to L$, if:

$$\forall \epsilon > 0, \quad \exists N \in \mathbb{N} \quad \text{such that} \quad n > N \implies |a_n - L| < \epsilon$$

💡 The Archery Game Analogy

Think of the definition as a game between two players:

  1. 1. The Challenger sets tolerance ($\epsilon$): Your opponent hands you a tiny positive distance $\epsilon$, drawing a narrow target band around $L$.
  2. 2. You find a cutoff step ($N$): You determine how far down the list to walk—past index $N$—so everything settles inside the band.
  3. 3. The Tail Test ($\vert{}a_n - L\vert{} < \epsilon$): The absolute distance between $a_n$ and $L$ stays strictly smaller than $\epsilon$ for every step past $N$.

If you can respond with a valid $N$ no matter how tiny your opponent makes $\epsilon$, the sequence converges to $L$!

2. Quantifier Order, Scope, and Dependencies

💡 Quantifier Order, Scope, and Dependency

In formal analysis, statements often string together multiple quantifiers: $\forall \epsilon > 0 \quad \exists N \in \mathbb{N} \quad \forall n > N \dots$ To parse these without getting lost, think of them as nested scopes and sequential turns in a game.

⚙️ How Chained Quantifiers Actually Work
  1. Left-to-Right Evaluation Order: Quantifiers execute strictly from left to right. Inner variables can react to and depend on outer variables.
  2. Lexical Scope & Function Dependency: Because $N$ is nested inside $\forall \epsilon > 0$, $N$ is mathematically a function of $\epsilon$: $N = N(\epsilon)$.
  3. The Commutativity Rule: Quantifiers of the same type commute ($\forall x \forall y \equiv \forall y \forall x$). However, alternating quantifiers ($\forall \exists$ vs $\exists \forall$) cannot be swapped!
VariableScopeDependency Rule
$\epsilon$$\forall \epsilon > 0$Outer scope. Chosen independently of everything that follows.
$N$$\exists N \in \mathbb{N}$Inner to $\epsilon$. Chosen after inspecting $\epsilon$ ($N = N(\epsilon)$).
$n$$\forall n > N$Inner to both $\epsilon$ and $N$. Runs over all indices strictly past cutoff $N$.
⚠️ The Fatal Quantifier Swap ($\exists N \; \forall \epsilon$)

If you swap to $\exists N \in \mathbb{N} \; \forall \epsilon > 0 \; \forall n > N, |a_n - L| < \epsilon$, a single cutoff $N$ must satisfy all tolerances at once. The only distance smaller than every positive $\epsilon$ is zero, which forces $a_n = L$ for all $n > N$. This invalid swap accidentally restricts limits only to sequences that become permanently constant!

🎯 Worked Example: The $\epsilon\text{-}N$ Scratchpad Method

Prove formally that $\lim_{n\to\infty} \frac{2n+1}{n} = 2$:

  1. Step 1: The Scratchpad Analysis. Start with $|a_n - L| < \epsilon$: $$\left|\frac{2n+1}{n} - 2\right| = \left|2 + \frac{1}{n} - 2\right| = \frac{1}{n} < \epsilon$$
  2. Step 2: Solving for $n$. Rearranging gives $n > \frac{1}{\epsilon}$.
  3. Step 3: Choosing $N$. Pick any integer $N \ge \frac{1}{\epsilon}$ (explicitly $N = \lceil 1/\epsilon \rceil$).
  4. Step 4: Formal Proof Write-Up. Let $\epsilon > 0$ be given. Set $N = \lceil 1/\epsilon \rceil$. For any $n > N$, we have $n > \frac{1}{\epsilon} \implies \frac{1}{n} < \epsilon$, which guarantees $\left|\frac{2n+1}{n} - 2\right| < \epsilon$. $\blacksquare$

4. Properties of Convergent Sequences (Proposition 5)

Proposition 5 (Fundamental Limit Properties):
  1. Absolute Values: If $(a_n)$ converges to $L$, then $(|a_n|)$ converges to $|L|$.
  2. Boundedness: Every convergent sequence is bounded: $\exists M > 0$ such that $|a_n| \le M$ for all $n \in \mathbb{N}$.
  3. Preservation of Sign: If $\lim a_n = L > 0$, there exists an index $N_0$ such that $a_n > \frac{L}{2}$ for all $n > N_0$ (similarly, if $L < 0$, $a_n < \frac{L}{2}$ for all $n > N_0$).

📐 Proof Sketch: Why Convergence Implies Boundedness

Let $\lim a_n = L$. Choose $\epsilon = 1$. By definition, there is an index $N$ such that $|a_n - L| < 1$ for all $n > N$, meaning $L - 1 < a_n < L + 1$. The infinitely many tail terms are trapped in a bounded interval. The remaining finitely many initial terms $\{a_0, a_1, \dots, a_N\}$ have a well-defined maximum and minimum. Setting $M = \max(|a_0|, |a_1|, \dots, |a_N|, |L| + 1)$ bounds the entire sequence.

5. Algebraic Limit Laws and Proofs (Theorem 1)

Evaluating limits directly with $\epsilon\text{-}N$ proofs for every function is tedious. The Algebraic Limit Laws allow us to compute limits compositionally.

📐 Algebraic Limit Laws (Theorem 1)

Suppose $\lim_{n\to\infty} a_n = K$ and $\lim_{n\to\infty} b_n = L$, and let $c \in \mathbb{R}$ be a constant. Then:
1. Constant Rule: $\lim_{n\to\infty} c = c$
2. Scalar Multiple: $\lim_{n\to\infty} (c \cdot a_n) = c \cdot K$
3. Sum / Difference: $\lim_{n\to\infty} (a_n \pm b_n) = K \pm L$
4. Product Rule: $\lim_{n\to\infty} (a_n \cdot b_n) = K \cdot L$
5. Quotient Rule: $\lim_{n\to\infty} \left(\frac{a_n}{b_n}\right) = \frac{K}{L}$, provided $L \neq 0$ and $b_n \neq 0$
6. Power Rule: $\lim_{n\to\infty} (a_n)^p = K^p$

🎯 Rigorous Proof of the Sum Law

We prove that $\lim (a_n + b_n) = K + L$. Let $\epsilon > 0$.

  1. Since $a_n \to K$, $\exists N_1$ such that $n > N_1 \implies |a_n - K| < \frac{\epsilon}{2}$.
  2. Since $b_n \to L$, $\exists N_2$ such that $n > N_2 \implies |b_n - L| < \frac{\epsilon}{2}$.
  3. Let $N = \max(N_1, N_2)$. For any $n > N$, applying the Triangle Inequality yields: $$|(a_n + b_n) - (K + L)| = |(a_n - K) + (b_n - L)| \le |a_n - K| + |b_n - L| < \frac{\epsilon}{2} + \frac{\epsilon}{2} = \epsilon$$

6. Proving Non-Existence of Limits

To show that a sequence $(a_n)$ does not converge to any limit, we must prove that every possible candidate $L \in \mathbb{R}$ fails the $\epsilon\text{-}N$ definition:

$$\forall L \in \mathbb{R}, \quad \exists \epsilon > 0 \quad \text{such that} \quad \forall N \in \mathbb{N}, \quad \exists n > N \quad \text{with} \quad |a_n - L| \ge \epsilon$$

🎯 Proof: $a_n = (-1)^n$ Has No Limit

Consider the alternating sequence $(1, -1, 1, -1, \dots)$. Fix any $L \in \mathbb{R}$ and set $\epsilon = 1$.

  • Case 1 ($\vert{}L - 1\vert{} < 1$): In this case $L > 0$. For any odd index $n$, $a_n = -1$, giving $|a_n - L| = |-1 - L| = 1 + L > 1 = \epsilon$.
  • Case 2 ($\vert{}L - 1\vert{} \ge 1$): For any even index $n$, $a_n = 1$, giving $|a_n - L| = |1 - L| \ge 1 = \epsilon$.

In both cases, terms oscillate outside the $\epsilon = 1$ band for arbitrarily large $n$. Thus, no limit $L$ exists.
