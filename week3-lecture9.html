Week 3, Lecture 9: Continuity of Functions

Welcome to Lecture 9: The Anatomy of Unbroken Curves

We intuitively know what it means for a line to be "continuous"—you can draw it with a pencil without lifting the tip off the paper. But intuition is not enough in mathematics. How do we rigorously guarantee that a curve has no microscopic holes, no sudden jumps, and no infinite breaks?

In Week 2, we mastered the $\epsilon$-$N$ definition of limits for sequences, where we chased numbers out to infinity. Today, we bring that same rigorous trapping mechanism to functions. Instead of traveling out to $n \to \infty$, we will zoom in on a single specific point ($x_0$).

In this lecture, we introduce the formal $\epsilon$-$\delta$ (epsilon-delta) definition of continuity, explore how to control output errors by restricting input errors, and look at the profound guarantees that continuity provides, such as the Intermediate Value Theorem.

1. The Physical Intuition: Controlling the Error

In practice, we rarely have perfectly exact inputs. Imagine a firefighter shooting a water jet to hit a specific window. A small error in the angle of the hose (the input, $x$) creates a corresponding error in where the water lands (the output, $y$).

The central question of continuity is: Can we guarantee a desired output precision by demanding a sufficiently strict input precision?

  • Let $\epsilon$ (epsilon) be the maximum acceptable error in our output: $|f(x) - f(x_0)| < \epsilon$.
  • Let $\delta$ (delta) be the strict tolerance we place on our input: $|x - x_0| < \delta$.

🎯 Example: Controlling a Linear Function

Suppose we are working with a linear function $f(x) = mx + b$ (where $m \neq 0$). We want to ensure our output is within an $\epsilon$-corridor around our target $f(x_0)$.

$$|f(x) - f(x_0)| < \epsilon$$

Let's expand the function algebraically:

$$|(mx + b) - (mx_0 + b)| = |m(x - x_0)| = |m| \cdot |x - x_0| < \epsilon$$

If we divide by the slope $|m|$, we isolate the input distance:

$$|x - x_0| < \frac{\epsilon}{|m|}$$

The Verdict: We successfully found our input tolerance! If we restrict our input $x$ such that its distance to $x_0$ is strictly less than $\delta = \frac{\epsilon}{|m|}$, we mathematically guarantee that the output error will be less than $\epsilon$.

2. The Formal $\epsilon$-$\delta$ Definition

The example above demonstrates that for a continuous function, no matter how tiny the output tolerance $\epsilon$ becomes, we can always find a corresponding input tolerance $\delta$ to trap the function. This is the formal definition of continuity at a point.

Definition: Continuity at a Point $x_0$

A function $f: X \to \mathbb{R}$ is continuous at a point $x_0 \in X$ if for every positive number $\epsilon > 0$, there exists a positive number $\delta > 0$ such that for all $x \in X$, the condition $|x - x_0| < \delta$ strictly implies $|f(x) - f(x_0)| < \epsilon$.

$$\forall \epsilon > 0, \ \exists \delta > 0 \text{ such that } \forall x \in X, \ |x - x_0| < \delta \implies |f(x) - f(x_0)| < \epsilon$$

Just like with sequence limits, this is a formal game. The adversary hands you an impossibly tight output margin ($\epsilon$), and you must calculate a specific input window ($\delta$) that acts as a secure mathematical fence.

3. When Continuity Fails (Discontinuity)

What happens when a function physically breaks? To prove a function is discontinuous, we must step into the role of the skeptic and defeat the $\epsilon$-$\delta$ trap. We must find just one lethal error margin $\epsilon$ where, no matter how tightly the defender shrinks their $\delta$ window, the function still manages to break out of the $\epsilon$-corridor.

⚠️ Example: The Step Function (A Sudden Jump)

Consider a function that models a sudden switch being flipped:

$$f(x) = \begin{cases} 1 & \text{for } x \ge 0 \\ 0 & \text{for } x < 0 \end{cases}$$

Let's test continuity at $x_0 = 0$. The target output is $f(0) = 1$.

As the skeptic, we set a tight tolerance of $\epsilon = 0.5$. We demand that all outputs stay within $0.5$ units of the target $1$.

Can the defender find a $\delta$ window around $x_0 = 0$ to satisfy this? No. No matter how incredibly small they make $\delta$ (even $\delta = 0.00001$), their input window will always contain some negative numbers. For any negative input, the function outputs $0$, which is a full distance of $1.0$ away from the target, utterly violating the $\epsilon = 0.5$ rule. The trap fails, proving the function is discontinuous at $x_0 = 0$.

4. The Power of Continuity: The Intermediate Value Theorem

Once a function is proven to be strictly continuous on a closed interval $[a, b]$, it gains profound mathematical properties. It is guaranteed to be bounded (it cannot shoot to infinity), it is guaranteed to have an absolute maximum and minimum, and it possesses the property of hitting every single value in between.

🌉 The Intermediate Value Theorem (IVT)

A continuous curve cannot skip over values.

If $f$ is a continuous function on the closed interval $[a, b]$, and $k$ is any number strictly between $f(a)$ and $f(b)$, then there is guaranteed to be at least one input $c$ in the interval $(a, b)$ such that $f(c) = k$.

The Intermediate Value Theorem is incredibly powerful for finding roots. If a continuous function is negative at $x=1$ and positive at $x=2$, it must have crossed exactly zero somewhere in between. We don't have to know the algebraic formula to guarantee that the root physically exists!
