1. Set Theory Foundations

📖 Notation Reference: Set Theory

Getting comfortable with set notation: Symbols like $\in$, $\subseteq$, $\cup$, and $\cap$ simply provide shorthand precision for describing collections, containment, and combinations.
$x \in A$$x$ is an element of set $A$
$x \notin A$$x$ is not an element of set $A$
$A \subseteq B$$A$ is a subset of $B$
$A \subset B$$A$ is a proper subset of $B$ ($A \subseteq B$ and $A \neq B$)
$\emptyset$The empty set (contains no elements)
$\mathcal{P}(A)$Power set: collection of all subsets of $A$
$A \cup B$Union: elements in $A$, $B$, or both
$A \cap B$Intersection: elements in both $A$ and $B$
$A \setminus B$Relative complement: elements in $A$ but not in $B$
$A \times B$Cartesian product: set of ordered pairs $(a, b)$
$\mid$   or   $:$"Such that" (used as a filter condition)

A set is any well-defined collection of distinct mathematical objects, called elements. If $x$ is an element of set $A$, we write $x \in A$; otherwise, $x \notin A$.

Specifying Sets:

  • Roster Notation: Explicitly listing members within braces, e.g., $A = \{2, 3, 5, 7\}$.
  • Set-Builder Notation: Specifying members by a property: $B = \{ x \in \mathbb{N} \mid x \text{ is prime and } x < 10 \}$.

Anatomy of Set-Builder Notation

Set-builder notation is standard when specifying continuous intervals or infinite sets:

$$A = \{ x \in S \mid P(x) \}$$

  • $x$: The candidate variable.
  • $\in S$: The universe or domain where candidates are chosen from (e.g., $x \in \mathbb{R}$).
  • $\mid$ or $:$: Read as "such that".
  • $P(x)$: The predicate or condition candidates must satisfy.

Subsets and the Power Set

A set $A$ is a subset of $B$ (denoted $A \subseteq B$) if every element of $A$ is also an element of $B$. If $A \subseteq B$ but $A \neq B$, then $A$ is a proper subset ($A \subset B$). The empty set $\emptyset$ satisfies $\emptyset \subseteq A$ for every set $A$.

The Power Set $\mathcal{P}(A)$:

The power set of a set $A$, denoted $\mathcal{P}(A)$, is the set of all subsets of $A$.

If $A$ is a finite set with $n$ elements, then its power set has exactly $2^n$ elements:

$$|\mathcal{P}(A)| = 2^n$$

For example, if $A = \{1, 2\}$, the subsets of $A$ are:

  1. The subset with zero elements: $\emptyset$
  2. Subsets with one element: $\{1\}$ and $\{2\}$
  3. The subset with two elements: $\{1, 2\}$

Therefore, $\mathcal{P}(A) = \{ \emptyset, \{1\}, \{2\}, \{1, 2\} \}$, giving $|\mathcal{P}(A)| = 2^2 = 4$ elements.

2. The Hierarchy of Number Systems

📖 Notation Reference: Number Systems

Number systems and algebraic structure: One useful way to understand the familiar number systems is to see how each provides solutions to equations that could not be solved within a smaller system.
$\mathbb{N}$Natural numbers: counting numbers $\{1, 2, 3, \dots\}$
$\mathbb{Z}$Integers: $\{\dots, -2, -1, 0, 1, 2, \dots\}$
$\mathbb{Q}$Rational numbers: quotients $\{p/q \mid p, q \in \mathbb{Z}, q \neq 0\}$
$\mathbb{R}$Real numbers: rational and irrational numbers
$\subset$Strict set containment: $\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}$
$[a, b]$Closed interval: $\{x \in \mathbb{R} \mid a \le x \le b\}$
$(a, b)$Open interval: $\{x \in \mathbb{R} \mid a < x < b\}$
Nested Set Containment Hierarchy ($\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}$)

💡 Context: Expanding Systems to Solve Equations

Examining equations that fail to have solutions in smaller systems illustrates why larger systems are constructed:

  • In $\mathbb{N}$, the equation $x + 5 = 2$ has no solution. Adjoining additive inverses forms $\mathbb{Z}$.
  • In $\mathbb{Z}$, the equation $2x = 3$ has no solution. Adjoining multiplicative inverses forms the field of rationals $\mathbb{Q}$.
  • In $\mathbb{Q}$, the equation $x^2 = 2$ has no solution. Adjoining irrational limits forms the real numbers $\mathbb{R}$.

Real Numbers and Completeness

Between any two rational numbers, another rational number exists (the rationals are dense). However, $\mathbb{Q}$ still contains "holes" geometrically: the diagonal of a unit square has length $\sqrt{2}$, yet no rational number satisfies $(p/q)^2 = 2$.

The Geometric Gap: Constructing √2 on the Number Line

Completeness of $\mathbb{R}$:

  • Intuition: Completeness ensures that the real number line has no "gaps" or missing points.
  • Formal Property (Least Upper Bound Axiom): Every non-empty subset of $\mathbb{R}$ that is bounded above has a least upper bound (supremum) in $\mathbb{R}$.

3. Sequences and the Limit Concept

📖 Notation Reference: Sequences & Limits

$\forall$Universal quantifier: "for all" or "for every"
$\exists$Existential quantifier: "there exists"
$(a_n)$Sequence: an ordered list $(a_1, a_2, a_3, \dots)$
$a_n$General term of the sequence at index $n \in \mathbb{N}$
$\lim_{n\to\infty} a_n = L$The sequence $a_n$ converges to limit $L$
$\epsilon > 0$Arbitrary positive distance tolerance
$N \in \mathbb{N}$Cutoff index past which terms satisfy $|a_n - L| < \epsilon$

Formally, a sequence of real numbers is a function $f: \mathbb{N} \to \mathbb{R}$. We denote the output $f(n)$ as $a_n$, expressing the sequence as $(a_n)_{n=1}^\infty$.

The Formal Definition of Convergence

A sequence $(a_n)$ converges to a limit $L$, written $\lim_{n\to\infty} a_n = L$, if:

$$\forall \epsilon > 0, \quad \exists N \in \mathbb{N} \quad \text{such that} \quad \forall n > N, \quad |a_n - L| < \epsilon$$

Logical Rationale

💡 Quantifier Order and Dependency

Quantifiers are read from left to right, creating a clear dependency chain:

Variable Scope Dependency Rule
$\epsilon$ $\forall \epsilon > 0$ Arbitrary positive tolerance, chosen independently of $N$.
$N$ $\exists N \in \mathbb{N}$ Chosen after inspecting $\epsilon$. $N$ depends directly on $\epsilon$ (i.e. $N = N(\epsilon)$).
$n$ $\forall n > N$ Runs over all indices strictly past cutoff $N$.
⚠️ Why Quantifier Order Matters ($\forall \epsilon \, \exists N$ vs $\exists N \, \forall \epsilon$)
Standard Convergence: $\forall \epsilon > 0, \exists N \in \mathbb{N}$

"For any tolerance $\epsilon > 0$ you provide, a suitable index $N$ can be found."
Smaller tolerances typically require larger values of $N$.

Swapped Quantifiers: $\exists N \in \mathbb{N}, \forall \epsilon > 0$

"A single fixed $N$ exists that simultaneously satisfies every $\epsilon > 0$."
This is far stronger than ordinary convergence. It requires terms to eventually equal $L$ exactly ($a_n = L$ for all $n > N$), which fails for sequences like $1/n$ that only approach the limit asymptotically.
