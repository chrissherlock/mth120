Week 1: Sets, Numbers, and Sequences

A rigorous introduction to foundational set theory, axiomatic number systems, real completeness, and the calculus of discrete sequences.

Lecture 1
Sets, Operations, and Function Mappings

Sets and Infinite Cardinality

A set is an unordered collection of distinct elements. The elements can be numbers, functions, geometric vectors, or sets themselves. The fundamental relation is set membership ($x \in A$). The order in which elements are listed does not matter, and duplicate elements are redundant:

$$\{1, 2, 3\} = \{3, 2, 1\} = \{1, 1, 1, 2, 2, 3\}$$

The number of elements in a set $A$ is its cardinality, denoted $|A|$. The unique set containing no elements is the empty set, written $\emptyset = \{\}$, with $|\emptyset| = 0$.

When comparing infinite sets, cardinality provides a rigorous measure of size. The standard mathematical sets satisfy the inclusion chain:

$$\mathbb{N} \subseteq \mathbb{Z} \subseteq \mathbb{Q} \subseteq \mathbb{R} \subseteq \mathbb{C}$$

However, their infinite cardinalities do not strictly increase at each inclusion. Natural numbers, integers, and rational numbers share the same countable infinity, whereas the continuum of real and complex numbers forms a strictly larger tier:

$$\infty = |\mathbb{N}| = |\mathbb{Z}| = |\mathbb{Q}| \le |\mathbb{R}| = |\mathbb{C}|$$

Axiomatic Foundations: Peano's Axioms for $\mathbb{N}$

Before constructing algebraic fields or real analysis metrics, the natural numbers $\mathbb{N}$ must be rigorously grounded. Rather than taking the process of counting for granted, the natural numbers are formally characterized by Peano's axioms, which specify a base element $0 \in \mathbb{N}$ and a unary successor function $S: \mathbb{N} \to \mathbb{N}$ (intuitively representing $S(n) = n + 1$):

  1. Existence of Zero (Base Element): $0 \in \mathbb{N}$. Ensures that the set of natural numbers is non-empty and provides a foundational root.
  2. Closure Under Successor: $\forall n \in \mathbb{N}, \; S(n) \in \mathbb{N}$. Every natural number has an unambiguously defined successor in $\mathbb{N}$.
  3. Injectivity of Successor (No Branching / Merging): $\forall m, n \in \mathbb{N}, \; S(m) = S(n) \implies m = n$. Distinct numbers cannot have identical successors. In graph-theoretic terms, every node has an in-degree of at most 1, preventing multiple paths from collapsing into one another.
  4. Non-Surjectivity onto Zero (No Predecessor / No Cycles): $\forall n \in \mathbb{N}, \; S(n) \ne 0$. Zero is not the successor of any natural number ($0 \notin \text{range}(S)$). This prevents cyclic wrap-around paths (such as finite clock arithmetic $\mathbb{Z}/n\mathbb{Z}$) and establishes $0$ as the strict starting origin.
  5. Axiom of Induction (Connectedness & Minimality): Let $K \subseteq \mathbb{N}$. If $0 \in K$ and $[\forall n \in \mathbb{N}, \; (n \in K \implies S(n) \in K)]$, then $K = \mathbb{N}$.
    While axioms 1–4 prevent loops and branching, they still permit disconnected "ghost chains" (isolated infinite linear components or cycles unlinked to $0$). The induction axiom serves as a minimality condition, guaranteeing that $\mathbb{N}$ contains only those elements generated by applying $S$ finitely many times starting from $0$.

From this minimalist framework, all arithmetic operations are defined recursively without circularity:

  • Addition ($+$): Defined inductively by $n + 0 = n$ and $n + S(m) = S(n + m)$.
  • Multiplication ($\cdot$): Defined inductively by $n \cdot 0 = 0$ and $n \cdot S(m) = (n \cdot m) + n$.

The standard algebraic laws—associativity, commutativity, and distributivity—all follow directly as formal theorems proved via mathematical induction.

Set Operations and Cartesian Products

Given subsets $A$ and $B$ within a universal domain, the standard algebraic operations on sets are defined as:

  • Union: $A \cup B = \{x : x \in A \text{ or } x \in B\}$. Note $A \cup \emptyset = A$.
  • Intersection: $A \cap B = \{x : x \in A \text{ and } x \in B\}$. Note $A \cap \emptyset = \emptyset$.
  • Difference (Relative Complement): $A \setminus B = \{x : x \in A \text{ and } x \notin B\}$. Note that difference is non-commutative: $A \setminus B \ne B \setminus A$.
  • Cartesian Product: $A \times B = \{(a, b) : a \in A, b \in B\}$ (the set of ordered pairs). The cardinality of a finite product satisfies $|A \times B| = |A| \times |B|$. When applied to the real numbers, $\mathbb{R} \times \mathbb{R} = \mathbb{R}^2$ forms the two-dimensional Cartesian plane.

Function Mappings, Bijectivity, and Inverses

A function $f: X \to Y$ is a rule assigning each input $x \in X$ exactly one output $f(x) \in Y$. Here, $X$ is the domain, $Y$ is the codomain, and the set of actual outputs forms the range:

$$\text{range}(f) = \{f(x) : x \in X\} \subseteq Y$$

Functions are classified according to how they cover their codomain and preserve distinctness:

  • Surjective (Onto): A function is surjective if its range equals its codomain ($\text{range}(f) = Y$). Every element $y \in Y$ has at least one pre-image $x \in X$ such that $f(x) = y$.
  • Injective (One-to-One): A function is injective if distinct inputs yield distinct outputs: $$\forall x_1, x_2 \in X, \quad x_1 \ne x_2 \implies f(x_1) \ne f(x_2) \quad (\text{equivalently, } f(x_1) = f(x_2) \implies x_1 = x_2)$$ Counterexample: $f: \mathbb{Z} \to \mathbb{Z}$ defined by $f(x) = x^2$ is not injective because $f(-1) = 1 = f(1)$.
  • Bijective: A function that is both injective and surjective.
  • Composition: Given $f: X \to Y$ and $g: Y \to Z$, the composite function $(g \circ f): X \to Z$ is evaluated by $(g \circ f)(x) = g(f(x))$.
  • Inverse Functions: A function $f: X \to Y$ has a two-sided inverse $f^{-1}: Y \to X$ if and only if $f$ is bijective. The inverse satisfies: $$(f^{-1} \circ f)(x) = f^{-1}(f(x)) = x \quad \forall x \in X, \qquad (f \circ f^{-1})(y) = f(f^{-1}(y)) = y \quad \forall y \in Y$$
Lecture 2
Numbers, Metric Properties, and Completeness

Density of the Rational Numbers

Proposition 1: For any two distinct rational numbers $a$ and $b$, there exist infinitely many rational numbers strictly between them.
Proof Without loss of generality, assume $a < b$. Consider the arithmetic mean: $$c_1 = \frac{a + b}{2}$$ Since $a, b \in \mathbb{Q}$ and the rationals are closed under addition and non-zero division, $c_1 \in \mathbb{Q}$. Testing bounds: $$c_1 - a = \frac{a + b}{2} - a = \frac{b - a}{2} > 0 \implies a < c_1$$ $$b - c_1 = b - \frac{a + b}{2} = \frac{b - a}{2} > 0 \implies c_1 < b$$ Hence $a < c_1 < b$. Applying the exact same argument to $a$ and $c_1$ yields $c_2 = \frac{a + c_1}{2} \in \mathbb{Q}$ with $a < c_2 < c_1 < b$. Repeating this process indefinitely constructs an infinite sequence of distinct rational numbers: $$b > c_1 > c_2 > c_3 > \dots > a$$

Rational Holes and the Irrationality of $\sqrt{2}$

Despite the rational numbers being dense across the line, $\mathbb{Q}$ is full of structural "holes." Consider an isosceles right triangle with unit legs ($1$ and $1$). By Pythagoras' theorem, the hypotenuse $c$ satisfies $c^2 = 1^2 + 1^2 = 2 \implies c = \sqrt{2}$.

Proof of Irrationality via Unique Prime Factorisation Assume, for contradiction, that $\sqrt{2}$ is rational: $\sqrt{2} = \frac{p}{q}$ for positive integers $p, q$ with $q \ne 0$. Squaring both sides: $$\frac{p^2}{q^2} = 2 \implies p^2 = 2q^2$$ By the Fundamental Theorem of Arithmetic, every integer greater than 1 factors uniquely into a product of prime numbers. In the prime factorisation of any perfect square ($n^2$), every distinct prime factor must appear raised to an even power. Therefore:
  • The prime factorisation of $p^2$ contains an even number of prime factors (counting multiplicities).
  • The prime factorisation of $q^2$ contains an even number of prime factors. Multiplying by 2 adds exactly one additional prime factor, meaning $2q^2$ contains an odd number of prime factors.
Because unique prime factorisation is invariant, an integer with an even number of prime factors cannot equal an integer with an odd number of prime factors ($p^2 \ne 2q^2$). This contradiction proves $\sqrt{2} \notin \mathbb{Q}$.

Axiomatic Field and Order Properties of $\mathbb{R}$

To resolve the gaps in $\mathbb{Q}$, we construct the set of real numbers $\mathbb{R}$ combining rational and irrational quantities. Formally, $\mathbb{R}$ is an ordered field satisfying:

  • Field Axioms: Commutativity and associativity of addition and multiplication; distributivity ($(a+b)c = ac + bc$); additive identity $0$ and multiplicative identity $1 \ne 0$; additive inverses ($-a$) and multiplicative reciprocals ($a^{-1}$ for $a \ne 0$).
  • Trichotomy: For any $a, b \in \mathbb{R}$, exactly one of the following holds: $a > b$, $a = b$, or $a < b$.
  • Order Transitivity: $a > b \text{ and } b > c \implies a > c$.
  • Order Preservation: If $a > b$, then $a + c > b + c$ for all $c \in \mathbb{R}$. If $a > b$ and $c > 0$, then $ac > bc$.

Absolute Value, Metric Distance, and the Triangle Inequality

The absolute value function $|\cdot|: \mathbb{R} \to \mathbb{R}$ is defined piecewise:

$$|x| = \begin{cases} x & \text{if } x \ge 0 \\ -x & \text{if } x < 0 \end{cases}$$

It establishes the standard metric distance on the real line: $\text{dist}(a, b) = |a - b|$.

Proposition 2 (Properties of Absolute Value):
  1. $|a| \ge 0$ for all $a \in \mathbb{R}$, with $|a| = 0 \iff a = 0$.
  2. $|ab| = |a| \cdot |b|$ for all $a, b \in \mathbb{R}$.
  3. $|a|^2 = a^2$ for all $a \in \mathbb{R}$.
  4. Triangle Inequality: $|a + b| \le |a| + |b|$ for all $a, b \in \mathbb{R}$.
  5. Reverse Triangle Inequality: $||a| - |b|| \le |a - b|$ for all $a, b \in \mathbb{R}$.
Proof of the Triangle Inequality Observe that for any real number $x$, $-|x| \le x \le |x|$. We examine two exhaustive cases for the sum $a+b$:
  • Case 1 ($a + b \ge 0$): By definition, $|a + b| = a + b$. Since $a \le |a|$ and $b \le |b|$, summing inequalities gives $|a + b| = a + b \le |a| + |b|$.
  • Case 2 ($a + b < 0$): By definition, $|a + b| = -(a + b) = (-a) + (-b)$. Since $-a \le |a|$ and $-b \le |b|$, summing gives $|a + b| = (-a) + (-b) \le |a| + |b|$.
In both cases, $|a + b| \le |a| + |b|$.

Bounds, Suprema, and the Completeness of $\mathbb{R}$

Let $S \subseteq \mathbb{R}$ be a non-empty subset:

  • Upper Bound: A real number $K$ is an upper bound for $S$ if $x \le K$ for all $x \in S$. If such a $K$ exists, $S$ is bounded above.
  • Lower Bound: A real number $k$ is a lower bound for $S$ if $k \le x$ for all $x \in S$. If such a $k$ exists, $S$ is bounded below.
  • Bounded Set: A set that is bounded both above and below. Bounded intervals include closed $[a, b]$, open $(a, b)$, and half-open $(a, b], [a, b)$. Unbounded intervals include $[a, \infty), (-\infty, b)$, and $(-\infty, \infty)$.
  • Supremum ($\sup S$): The least upper bound of $S$. A number $s = \sup S$ satisfies:
    1. $s$ is an upper bound: $\forall x \in S, \; x \le s$.
    2. $s$ is the minimal upper bound: If $K$ is any upper bound for $S$, then $s \le K$.
  • Infimum ($\inf S$): The greatest lower bound of $S$.
The Axiom of Completeness: Every non-empty subset of real numbers that is bounded above has a supremum in $\mathbb{R}$.

The Rational Incompleteness Defect: The rational numbers do not satisfy completeness. Consider the subset $S = \{x \in \mathbb{Q} : x^2 < 2\} \subseteq \mathbb{Q}$. $S$ is non-empty and bounded above in $\mathbb{Q}$ (for instance, by $2$ or $10$). However, $\sup S = \sqrt{2} \notin \mathbb{Q}$. Within the universe of $\mathbb{Q}$, $S$ has no least upper bound.

Lecture 3
Sequences, Monotonicity, and Derived Sequences

Formal Definition of a Sequence

Formally, a sequence is a function whose domain is the natural numbers: $f: \mathbb{N} \to \mathbb{R}$. Rather than functional notation $f(n)$, we write $a_n$ and denote the sequence as an infinite, ordered list:

$$(a_n)_{n=0}^\infty = (a_0, a_1, a_2, a_3, \dots)$$

Standard architectural forms include:

  • Arithmetic Sequences: $c_n = an + b$, adding a constant difference $a$ at each step.
  • Geometric Sequences: $c_n = aq^n$ (with $a \ne 0, q \ne 0, 1$), multiplying by a constant factor $q$ at each step.
  • Monotonicity Properties: A sequence $(a_n)$ is:
    • Constant if $\exists c \in \mathbb{R}$ such that $\forall n, a_n = c$.
    • Positive (non-negative) if $\forall n, a_n > 0$ ($a_n \ge 0$).
    • Strictly increasing (increasing) if $\forall n, a_{n+1} > a_n$ ($a_{n+1} \ge a_n$).
    • Strictly decreasing (decreasing) if $\forall n, a_{n+1} < a_n$ ($a_{n+1} \le a_n$).

The Derived Sequence ($a'_n$)

Analogous to the derivative in differential calculus, the derived sequence $(a'_n)_{n=0}^\infty$ of a sequence $(a_n)_{n=0}^\infty$ measures discrete consecutive forward differences:

$$a'_n = a_{n+1} - a_n \implies (a'_n)_{n=0}^\infty = (a_1 - a_0, a_2 - a_1, a_3 - a_2, \dots)$$
Proposition 4: Let $(a_n)_{n=0}^\infty$ be a real sequence with derived sequence $(a'_n)_{n=0}^\infty$:
  1. $(a_n)$ is constant $\iff a'_n = 0$ for all $n$.
  2. $(a_n)$ is increasing (strictly increasing) $\iff a'_n \ge 0$ ($a'_n > 0$) for all $n$.
  3. $(a_n)$ is decreasing (strictly decreasing) $\iff a'_n \le 0$ ($a'_n < 0$) for all $n$.
Proof of Constancy via Induction ($\implies$) Suppose $a_n = c$ for all $n$. Then $a'_n = a_{n+1} - a_n = c - c = 0$.
($\impliedby$) Conversely, suppose $a'_n = 0$ for all $n$. Let $a_0 = c$. We proceed by induction on $n$.
Base Case: For $n = 0$, $a_1 = a_0 + (a_1 - a_0) = a_0 + a'_0 = c + 0 = c$.
Inductive Step: Assume $a_k = c$ for some $k \ge 0$. Then: $$a_{k+1} = a_k + (a_{k+1} - a_k) = a_k + a'_k = c + 0 = c$$ By mathematical induction, $a_n = c$ for all $n \in \mathbb{N}$, proving $(a_n)$ is constant.

Calculus of Standard Derived Sequences

Evaluating derived differences for elementary algebraic sequence types:

  • Arithmetic ($c_n = an + b$): $$c'_n = [a(n+1) + b] - [an + b] = an + a + b - an - b = a$$
  • Geometric ($c_n = aq^n$): $$c'_n = aq^{n+1} - aq^n = aq^n(q - 1)$$
  • Quadratic ($c_n = n^2$): $$c'_n = (n+1)^2 - n^2 = (n^2 + 2n + 1) - n^2 = 2n + 1$$

Inversion via Telescoping Sums and Gauss's Formula

Because derived sequences act as discrete differences, the original sequence can be recovered via the discrete analog of integration: telescoping summation. Expanding the sum of consecutive differences:

$$\sum_{k=0}^{n-1} a'_k = (a_1 - a_0) + (a_2 - a_1) + \dots + (a_n - a_{n-1}) = a_n - a_0$$

Rearranging yields the sequence reconstruction formula:

$$a_n = a_0 + \sum_{k=0}^{n-1} a'_k$$
Discrete Integration Example: Deriving Gauss's Summation Formula
Suppose we wish to evaluate $\sum_{k=0}^{n-1} k$, which is equivalent to finding a sequence $a_n$ whose derived sequence is $a'_n = n$ with $a_0 = 0$.
From our derived calculus:
  • $(n^2)' = 2n + 1$
  • $(n)' = 1$
By linearity of the difference operator: $$(n^2 - n)' = (2n + 1) - 1 = 2n \implies \left(\frac{n^2 - n}{2}\right)' = n$$ Therefore, the anti-difference of $a'_n = n$ is $a_n = \frac{n^2 - n}{2} = \frac{n(n-1)}{2}$. Applying telescoping inversion: $$\sum_{k=0}^{n-1} k = a_n - a_0 = \frac{n(n-1)}{2}$$ Shifting indices $k \mapsto k+1$ gives the Gaussian summation formula for the sum of the first $n$ positive integers: $$\sum_{k=1}^n k = \frac{n(n+1)}{2}$$
