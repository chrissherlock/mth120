1. Theoretical Foundations

We begin by formalizing collections of objects as sets ($A = \{1, 2, 3\}$) and mapping relationships via functions ($f: X \rightarrow Y$). This extends to the rigorous definition of sequences: functions mapping from $\mathbb{N}$ to $\mathbb{R}$, denoted $(a_n)_{n=0}^\infty$.

The $\epsilon-N$ Convergence Definition

A sequence $(a_n)$ converges to a limit $L$ if, for any error margin $\epsilon > 0$, there exists a threshold index $N$ such that for all $n > N$, the distance $\vert{}a_n - L\vert{} < \epsilon$.

PHASE: Initialization SEQ: a_n = 1/n n = 1 a_n = 1.000 ε = 0.2
Scenario: We are tracking consecutive measurements of a process that decays over time. We need to prove it eventually stabilizes near 0 within a strict tolerance ($\epsilon$).

What Is Happening (Mechanics)

The sequence initializes at $n=1$. The target limit is $L=0$. We establish an arbitrary error band $\epsilon = 0.2$ (the blue zone).

Why The System Does This (Rationale)

To rigorously prove convergence, we cannot just say "it gets smaller." We must demonstrate that the sequence can permanently enter and remain within *any* arbitrary boundary we set.
