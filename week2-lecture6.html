1. The Fallacy of Blind Algebra

⚠️ Putting the Cart Before the Horse

When given a recurrence $a_{n+1} = f(a_n)$, students often write $L = f(L)$ and solve for $L$. But this calculation is only legally valid after you have proven the limit exists!

The Fibonacci Counterexample: Consider the Fibonacci numbers $f_0 = 1, f_1 = 1$, and $f_{n+2} = f_{n+1} + f_n$ ($1, 1, 2, 3, 5, 8, 13, \dots$). If we blindly assume $\lim f_n = L$ exists:

$$L = L + L \implies L = 2L \implies L = 0$$

This is clearly false. Blind algebra assumes existence before proving it.

2. Continued Fractions & Error Contraction to $\sqrt{2}$

Consider the recurrence defined by $a_0 = 1$ and $a_{n+1} = \frac{a_n + 2}{a_n + 1}$:

$$a_0 = 1, \quad a_1 = \frac{3}{2} = 1.5, \quad a_2 = \frac{7}{5} = 1.4, \quad a_3 = \frac{17}{12} \approx 1.4167, \quad a_4 = \frac{41}{29} \approx 1.4138$$

🎯 Rigorous Proof of Convergence via Error Contraction

Let $\alpha_n = |a_n - \sqrt{2}|$ measure the distance to $\sqrt{2}$. Then:

$$\alpha_{n+1} = \left|\frac{a_n + 2}{a_n + 1} - \sqrt{2}\right| = \left|\frac{a_n + 2 - \sqrt{2}a_n - \sqrt{2}}{a_n + 1}\right| = \frac{\sqrt{2} - 1}{a_n + 1} |a_n - \sqrt{2}|$$

Since $\sqrt{2} - 1 < 0.5$ and $a_n \ge 1$ (so $\frac{1}{a_n+1} \le \frac{1}{2}$), we have $\frac{\sqrt{2}-1}{a_n+1} < \frac{1}{2}$, giving:

$$\alpha_{n+1} < \frac{1}{2}\alpha_n \implies 0 \le \alpha_n < \left(\frac{1}{2}\right)^n \alpha_0$$

Since $\lim_{n\to\infty} \left(\frac{1}{2}\right)^n = 0$, by the Squeeze Theorem $\alpha_n \to 0$, proving $\lim_{n\to\infty} a_n = \sqrt{2}$.

3. The 4-Step Strategy for Recurrences

🛠️ The 4-Step Strategy

  1. Step 1: Prove Boundedness. Use induction to show $a_n \le M$ (bounded above) or $a_n \ge m$ (bounded below).
  2. Step 2: Prove Monotonicity. Show $a_{n+1} \ge a_n$ (increasing) or $a_{n+1} \le a_n$ (decreasing).
  3. Step 3: Invoke the MCT. The Monotone Convergence Theorem guarantees a finite limit $L$ exists.
  4. Step 4: Solve Algebraically. Take the limit of both sides of $a_{n+1} = f(a_n)$ to find $L$.

🎯 Worked Example: Nested Radical $x_1 = \sqrt{2}, \; x_{n+1} = \sqrt{2 + x_n}$

  1. Boundedness: $x_1 < 2$. If $x_k < 2$, then $x_{k+1} = \sqrt{2 + x_k} < \sqrt{4} = 2$. Bounded above by 2.
  2. Monotonicity: $x_2 = \sqrt{2 + \sqrt{2}} > \sqrt{2} = x_1$. By induction, strictly increasing.
  3. MCT: Increasing and bounded above $\implies \lim x_n = L$ exists.
  4. Evaluation: $L = \sqrt{2 + L} \implies L^2 - L - 2 = 0 \implies (L-2)(L+1) = 0$. Since $x_n > 0$, $L = 2$.

4. Infinity as a Limit ($M\text{-}N$ Definition)

Definition: Divergence to $\pm \infty$ ($M\text{-}N$ Test):

A sequence tends to positive infinity ($\lim_{n\to\infty} a_n = \infty$) if:

$$\forall M > 0, \quad \exists N \in \mathbb{N} \quad \text{such that} \quad n > N \implies a_n > M$$

Similarly, $\lim_{n\to\infty} a_n = -\infty$ if for every $M < 0$, $\exists N \in \mathbb{N}$ such that $n > N \implies a_n < M$.

5. Growth Rates: Geometric vs. Linear Divergence

🎯 Theorem: Geometric Sequences Diverge Faster Than Linear Ones

Let $a_n = c r^n$ with $r > 1$ and $b_n = \alpha n + \beta$ ($\alpha > 0$). We prove $\frac{a_n}{b_n} \to \infty$ by showing $\frac{r^n}{n} \to \infty$.

Write $r = 1 + \epsilon$ for some $\epsilon > 0$. By the Binomial Formula:

$$r^n = (1 + \epsilon)^n \ge 1 + n\epsilon + \frac{n(n-1)}{2}\epsilon^2$$

Dividing by $n$:

$$\frac{r^n}{n} \ge \frac{1}{n} + \epsilon + \frac{n-1}{2}\epsilon^2$$

As $n \to \infty$, the term $\frac{n-1}{2}\epsilon^2$ grows without bound, forcing $\frac{r^n}{n} \to \infty$. Hence, exponential growth dominates any linear polynomial.
