Week 3, Lecture 7: Functions, Domains, and Inverses

Welcome to Lecture 7: Mapping the Continuum

Throughout Week 2, our focus rested entirely on sequences—lists of distinct, isolated numbers stepping one by one toward a destination. In Week 3, we transition from the discrete stepping stones of sequences into the continuous, fluid world of functions.

In this unit, we primarily consider functions defined on a subset $X$ of the real numbers $\mathbb{R}$. A function is not just an algebraic formula; it is a rigid structural mapping that assigns every element in a domain to exactly one element in a codomain. Today, we will formally review these mappings, explore what it takes to run a function in reverse (invertibility), and classify the foundational algebraic curves (linear, power, and rational functions) that we will bend and stretch in upcoming lectures.

1. The Natural Domain and Codomain

A function $f: X \to Y$ is an assignment from a set $X$ (the domain) to a set $Y$ (the codomain). When a function is given strictly by an algebraic formula, that formula may make sense for some arguments and completely break down for others (such as demanding division by zero).

Definition: The Natural Domain

The natural domain of a function $f(x)$ is the largest possible subset of the real numbers $\mathbb{R}$ where the formula is well-defined and mathematically valid.

For example, consider the function $f(x) = \frac{1}{x}$. This formula is well-defined for all real numbers except $x = 0$. Therefore, its natural domain is the union of two open intervals:

$$X = (-\infty, 0) \cup (0, \infty)$$

The graph of a function $f: X \to Y$ is the subset of the Cartesian product $X \times Y$ containing all coordinate pairs $(x, f(x))$. If the function has an inverse $f^{-1}: Y \to X$, the graph of the inverse is simply the graph of $f$ reflected perfectly across the diagonal line $y = x$.

2. Linear Functions and Monotonicity

The simplest algebraic curve is a straight line. A linear (or affine) function is defined by the formula:

$$f(x) = mx + b$$

where $m$ is the slope (the constant rate of change) and $b$ is the $y$-intercept. The natural domain of any linear function is all real numbers, $\mathbb{R}$.

🔄 Invertibility of Linear Functions

Does a linear function run in reverse? Yes, provided it isn't flat. If $m \neq 0$, every single output $y$ comes from exactly one input $x$ (it is injective), and every real number can be hit by the function (it is surjective). This makes it bijective.

We can find its inverse simply by solving $y = mx + b$ for $x$:

$$x = \frac{1}{m}y - \frac{b}{m} \implies f^{-1}(x) = \frac{1}{m}x - \frac{b}{m}$$

Monotonicity Guarantees Invertibility

Just like sequences, functions can be classified by their directional behavior. A function is strictly increasing if $x_1 < x_2 \implies f(x_1) < f(x_2)$. A linear function is strictly increasing if its slope $m > 0$, and strictly decreasing if $m < 0$.

📈 Theorem: Strict Monotonicity implies Injectivity

If a function is strictly monotone (always rising or always falling), it is guaranteed to be injective (1-to-1).

Proof: Assume $f(x)$ is strictly increasing. If we pick two different inputs $x_1 \neq x_2$, one must be smaller (say, $x_1 < x_2$). Because the function strictly increases, $f(x_1) < f(x_2)$. Since the outputs are unequal, no two inputs ever share an output. Therefore, the function is injective. $\blacksquare$

3. Power Functions: The Even/Odd Divide

Power functions take the form $f(x) = x^n$ where $n > 1$ is a natural number. Their behavior radically splits depending on whether $n$ is even or odd.

Even Powers ($n = 2m$)

  • Symmetry: $f(-x) = f(x)$. The graph is mirror-symmetric across the $y$-axis (an even function).
  • Range: It never dips below zero; the range is restricted strictly to $[0, \infty)$.
  • Invertibility: Because $f(-1) = f(1) = 1$, it fails the horizontal line test. It is not injective. To create an inverse (the even root $\sqrt[2m]{x}$), we must artificially restrict the domain to $X = [0, \infty)$ so it becomes strictly increasing.

Odd Powers ($n = 2m + 1$)

  • Symmetry: $f(-x) = -f(x)$. The graph is point-symmetric with respect to the origin (an odd function).
  • Range: It covers the entire vertical spectrum; the range is $\mathbb{R}$.
  • Invertibility: Odd powers are strictly increasing across their entire natural domain $\mathbb{R}$. By our theorem above, this guarantees they are naturally injective. The inverse function ($\sqrt[2m+1]{x}$) exists everywhere without restricting the domain.

4. Polynomials and Rational Functions

By combining power functions with scalar multiplication and addition, we build polynomials:

$$f(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0$$

The natural domain of any polynomial is the set of all real numbers $\mathbb{R}$. If $x_0$ is a root of the polynomial (meaning $f(x_0) = 0$), the polynomial can be factored cleanly into $f(x) = (x - x_0)g(x)$ using long division.

A rational function is formed by taking the ratio of two polynomials:

$$f(x) = \frac{p(x)}{q(x)}$$

The natural domain of a rational function is all real numbers except the roots of the denominator polynomial $q(x)$. Negative power functions like $f(x) = x^{-n} = \frac{1}{x^n}$ are just specialized rational functions where the domain must strictly exclude $x = 0$.
