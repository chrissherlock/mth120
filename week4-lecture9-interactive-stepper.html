Practice Problems: Continuity & The IVT

Phase 1: Visual & Geometric Intuition
Problem 1: Geometric Meaning of the Delta Fence

In the formal definition of continuity, what does the inequality $|x - x_0| < \delta$ represent geometrically on a graph?

Problem 2: Geometric Meaning of the Epsilon Corridor

Similarly, what does the inequality $|f(x) - f(x_0)| < \epsilon$ represent geometrically?

Problem 3: The Role of the Adversary

In the $\epsilon$-$\delta$ proof game, what does the adversary's choice of $\epsilon$ represent?

Problem 4: The Grand Arc of Calculus

Why did mathematicians spend centuries developing this rigorous $\epsilon$-$\delta$ definition of continuity instead of just trusting the intuition of "drawing a line without lifting your pencil"?

Phase 2: Translating to Formal Game Mechanics
Problem 5: Three Pillars of Continuity

A function $f(x)$ is considered fully continuous at a point $x=c$ only if three conditions are met. Which of the following is NOT one of those three conditions?

Problem 6: Translating Quantifiers (Existential)

In the formal definition of continuity ($\forall \epsilon > 0, \exists \delta > 0$), what is the strict logical meaning of the $\exists$ (Existential) quantifier applied to $\delta$?

Problem 7: The Universality of the Formula

In the formal $\epsilon$-$\delta$ definition ($\forall \epsilon > 0, \exists \delta > 0 \dots$), why is the $\forall$ (Universal quantifier) placed on $\epsilon$ instead of $\delta$?

Problem 8: Shrinking the Delta Fence

You are defending a continuous function. The adversary sets $\epsilon = 0.5$. You calculate that an input tolerance of $\delta = 0.1$ perfectly traps the function. If you decide to be extra cautious and use $\delta = 0.05$ instead, what happens?

Phase 3: Calculating the Bounds
Problem 9: The Epsilon-Delta Machine

You are operating a machine governed by the linear function $f(x) = 5x - 2$. Your perfect target output is $f(3) = 13$. The adversary demands an output tolerance of $\epsilon = 0.5$. What is the required input tolerance $\delta$ around $x_0 = 3$ to mathematically guarantee $|f(x) - 13| < 0.5$?

Problem 10: Epsilon-Delta for a Negative Slope

You are testing continuity for $f(x) = -2x + 5$ at $x_0 = 1$. The target output is $f(1) = 3$. If the adversary chooses $\epsilon = 0.4$, what is the strictly required $\delta$?

Problem 11: Fractional Linear Delta

For the function $f(x) = \frac{1}{2}x + 4$, the adversary chooses $\epsilon = 0.1$. What $\delta$ is required?

Problem 12: Non-Linear Epsilon-Delta Scaling

For a strictly increasing curve that curves upward (like $f(x) = x^2$ for $x > 0$), what happens to the required $\delta$ window as you move further to the right along the x-axis, assuming the adversary's $\epsilon$ remains the same?

Phase 4: When the System Breaks (Discontinuities)
Problem 13: Removable Discontinuities

Suppose a function $g(x)$ is defined such that $\lim_{x \to 3} g(x) = 5$, but the actual evaluated function gives $g(3) = 8$. What type of discontinuity exists at $x = 3$?

Problem 14: Jump Discontinuities

If you calculate the left-hand limit of $f(x)$ as $x \to 2^-$ and get $4$, and calculate the right-hand limit as $x \to 2^+$ and get $7$, what can you conclude about the function at $x=2$?

Problem 15: Algebraic Hole Evaluation

Consider $f(x) = \frac{x^2 - 16}{x - 4}$. The function is undefined at $x=4$ (yielding $\frac{0}{0}$). If you factor the numerator and cancel the problematic term, what is the intended limit as $x \to 4$?

Problem 16: Anatomy of the Discontinuity Jailbreak

Consider the step function $H(x)$ which equals $0$ for $x < 0$ and $1$ for $x \ge 0$. We want to prove it is discontinuous at $x_0 = 0$. The adversary sets $\epsilon = 0.2$ around the target output $H(0) = 1$. Why does the defender's $\delta$-trap fail?

Phase 5: The IVT Superpower
Problem 17: Intermediate Value Theorem Guarantees

Suppose $f(x)$ is a strictly continuous function on the closed interval $[1, 5]$. You are given that $f(1) = -4$ and $f(5) = 12$. Which of the following statements is mathematically guaranteed by the IVT?

Problem 18: Real-World IVT

At 8:00 AM, the outside temperature was $15^\circ\text{C}$. At 12:00 PM, the temperature was $25^\circ\text{C}$. Assuming temperature changes continuously, what does the IVT guarantee?

Problem 19: The IVT and Polynomials

Why is the Intermediate Value Theorem always safe to use on any standard polynomial function (e.g., $f(x) = x^4 - 3x^2 + 2$) over any closed interval $[a, b]$?

Problem 20: Existence of Roots

Let $f(x) = x^3 + x - 1$. You evaluate $f(0) = -1$ and $f(1) = 1$. What does the Intermediate Value Theorem allow you to conclude?

Problem 21: Transcendental Root Proving

Let $f(x) = \cos(x) - x$. You evaluate the interval $[0, \frac{\pi}{2}]$. Given $f(0) = 1$ and $f(\frac{\pi}{2}) = -\frac{\pi}{2}$, what does the IVT conclude?

Problem 22: Exponential IVT

Consider $f(x) = e^x - 4$ on the interval $[0, 2]$. We know $e^0 = 1$ and $e^2 \approx 7.389$. Thus, $f(0) = -3$ and $f(2) \approx 3.389$. Does $e^x = 4$ have a solution in this interval?

Problem 23: The IVT Domain Trap

Consider the function $g(x) = \frac{1}{x-3}$. We evaluate the function at $x = 2$ and $x = 4$, finding $g(2) = -1$ and $g(4) = 1$. Because $0$ lies between $-1$ and $1$, does the IVT guarantee that a root $g(c) = 0$ exists in the interval $(2, 4)$?

Problem 24: Same-Sign IVT Trap

You test a continuous function $f(x)$ on $[2, 6]$ and find $f(2) = 4$ and $f(6) = 10$. Both outputs are positive. Does this guarantee that $f(x)$ has NO roots in the interval?

Problem 25: Bisection Method Logic

You are using the bisection algorithm to find a root of a continuous function $f(x)$ on the interval $[0, 4]$. You know $f(0)$ is negative and $f(4)$ is positive. You check the midpoint $c = 2$, and find that $f(2)$ is positive. What is your new, smaller interval guaranteed to contain the root?
