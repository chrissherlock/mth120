Practice Problems: Continuity & The IVT

Problem 1: Epsilon-Delta Factory Control

You are controlling a machine governed by the linear function $f(x) = 4x - 1$. Your target output is $7$ when your dial is set to $x_0 = 2$. If the safety inspector demands an output tolerance of $\epsilon = 0.1$, what is the strictly required input tolerance $\delta$ to guarantee $|f(x) - 7| < \epsilon$?

Correct! To find the input tolerance $\delta$, substitute the function into the output error inequality: $|(4x - 1) - 7| < 0.1$. Simplifying gives $|4x - 8| < 0.1$. Factor out the slope to get $4|x - 2| < 0.1$. Dividing by 4 yields $|x - 2| < 0.025$. Thus, the required $\delta$ is $0.025$.
Problem 2: The IVT Trap

Consider the function $f(x) = rac{1}{x}$. We evaluate the endpoints on the interval $[-1, 1]$ and find $f(-1) = -1$ and $f(1) = 1$. Because $0$ lies between $-1$ and $1$, does the Intermediate Value Theorem guarantee that $f(x) = 0$ has a root inside $[-1, 1]$?

Correct! The Intermediate Value Theorem strictly requires the function to be unbroken (continuous) across the entire closed interval. Because $f(x) = rac{1}{x}$ has a vertical asymptote at $x = 0$, the curve breaks completely, and the guarantee is destroyed.
Problem 3: Analyzing Discontinuity

A function is defined as $H(x) = 0$ for $x < 0$, and $H(x) = 1$ for $x \ge 0$. The adversary sets an error tolerance of $\epsilon = 0.2$ around the target output $f(0) = 1$. Why does the limit fail as $x o 0$?

Correct! Any input window ($\delta$) around $0$ will capture some negative $x$ values. For all negative $x$ values, the function outputs $0$, which is $1.0$ units away from the target output of $1$. This blatantly violates the strict $0.2$ error boundary, proving a jump discontinuity.
