Week 3, Lecture 8: Transcendental Functions

Welcome to Lecture 8: Beyond Algebra

In Lecture 7, we built our foundation on algebraic functions: linear equations, power functions, polynomials, and rational expressions. These are the "building blocks" of early mathematics because they can be computed using a finite sequence of additions, subtractions, multiplications, divisions, and root extractions.

However, nature does not restrict itself to algebra. Sound waves oscillate periodically. Bacteria populations compound and multiply. To model these phenomena, we need a new class of functions that transcend standard polynomial algebra. These are known as Transcendental Functions.

Today, we will formalize exponential growth, demystify the natural logarithm, and establish the geometric and analytical rules governing trigonometric waveforms and their inverses.

1. Exponential Functions

Unlike a power function ($x^n$) where the base varies and the exponent is constant, an exponential function locks the base in place and lets the exponent vary.

Definition: Exponential Function

For any positive real number $a > 0$ with $a \neq 1$, the exponential function is given by: $$f(x) = a^x$$

This function is defined for all real numbers (its natural domain is $\mathbb{R}$). While it is easy to understand $a^x$ when $x$ is a rational fraction like $p/q$, evaluating it for irrational exponents (like $a^{\sqrt{2}}$ or $a^\pi$) requires "filling the gaps" with limits to ensure the resulting function is smooth and unbroken.

Core Properties

  • Range: Exponential functions only output strictly positive numbers. Range: $(0, \infty)$.
  • Monotonicity: If $a > 1$, the function is strictly increasing. If $0 < a < 1$, it is strictly decreasing.
  • Rules of Exponents: For any real $x, y$:
    $a^{x+y} = a^x a^y \quad$ and $\quad (a^x)^y = a^{xy}$

2. Logarithmic Functions and Base $e$

Because $f(x) = a^x$ is strictly monotone across its entire domain, our theorem from Lecture 7 guarantees that it is injective. Because its range is $(0, \infty)$, it is surjective onto the positive real numbers. Therefore, it has a well-defined inverse function, called the logarithm.

🔄 The Logarithmic Inverse

The function $\log_a x$ answers the question: "To what power must I raise the base $a$ to obtain $x$?"

$\log_a x = y \iff a^y = x$

The domain of the logarithm is strictly the positive real numbers $(0, \infty)$, and its range is $\mathbb{R}$.

Because logarithms are the inverse of exponents, they inherit structural rules that flip the behavior of multiplication and addition:

  • $\log_a(xy) = \log_a x + \log_a y$
  • $\log_a(x^c) = c \log_a x$

Euler's Number and the Natural Logarithm

In Week 2, we evaluated a special limit using the Monotone Convergence Theorem: $\lim_{n \to \infty} (1 + 1/n)^n$. We proved that this sequence converges to an irrational constant, Euler's Number ($e \approx 2.718...$).

When $e$ is used as the base of an exponential function ($f(x) = e^x$), its inverse is so fundamental to calculus that it receives a special name: the Natural Logarithm, denoted as $\ln x$.

3. Trigonometric Functions: Sine and Cosine

The fundamental trigonometric functions are rooted in geometry, specifically the unit circle (a circle of radius 1 centered at the origin). If we draw a ray from the origin forming an angle $\theta$ (measured in radians) with the positive $x$-axis, it intersects the unit circle at exactly one point.

  • $\cos \theta$ is defined as the $x$-coordinate of this intersection point.
  • $\sin \theta$ is defined as the $y$-coordinate of this intersection point.

📐 Core Trigonometric Identities

Because the unit circle has the equation $x^2 + y^2 = 1$, we immediately get the Pythagorean Identity:

$$\sin^2 \theta + \cos^2 \theta = 1$$

Additionally, because adding $2\pi$ radians constitutes a full rotation back to the starting point, these functions are periodic:

$$\sin(\theta + 2\pi) = \sin \theta \quad \text{and} \quad \cos(\theta + 2\pi) = \cos \theta$$

You must also be familiar with the Addition Theorems, which govern how sine and cosine behave when angles are combined:

$$\sin(\theta + \phi) = \sin \theta \cos \phi + \cos \theta \sin \phi$$
$$\cos(\theta + \phi) = \cos \theta \cos \phi - \sin \theta \sin \phi$$

The Tangent Function

The tangent function is constructed as the ratio of sine to cosine: $\tan \theta = \frac{\sin \theta}{\cos \theta}$. Its natural domain excludes the points where $\cos \theta = 0$ (such as $\pi/2, 3\pi/2$, etc.), but its range spans all real numbers $\mathbb{R}$.

4. Inverse Trigonometric Functions

Because sine and cosine are periodic, they bounce back and forth between $-1$ and $1$. They are incredibly non-injective, meaning they spectacularly fail the horizontal line test.

To create inverse functions, we must artificially restrict their domains to a single interval where they act monotonically (strictly increasing or decreasing).

🎯 Domain Restrictions for Invertibility

  • Arcsine ($\arcsin x$): We restrict the sine function to the domain $[-\frac{\pi}{2}, \frac{\pi}{2}]$. On this interval, it strictly climbs from $-1$ to $1$.
    Inverse mapping: $\arcsin: [-1, 1] \to [-\frac{\pi}{2}, \frac{\pi}{2}]$.
  • Arccosine ($\arccos x$): We restrict the cosine function to the domain $[0, \pi]$. On this interval, it strictly falls from $1$ down to $-1$.
    Inverse mapping: $\arccos: [-1, 1] \to [0, \pi]$.
  • Arctangent ($\arctan x$): We restrict the tangent function to the open interval $(-\frac{\pi}{2}, \frac{\pi}{2})$, between its two vertical asymptotes. Here, it strictly increases from $-\infty$ to $\infty$.
    Inverse mapping: $\arctan: \mathbb{R} \to (-\frac{\pi}{2}, \frac{\pi}{2})$.
